# 八只股票批量查询与显示设计

## 目标

将现有单股票查询改为一次查询八只股票。交易时段每 5 秒更新，工作日午休每 10 分钟更新，其他时段不查询股票。八只股票代码可通过 Web 页面统一配置并持久化。

## 默认股票

1. `sh000001`
2. `sh000300`
3. `sz399006`
4. `sz399001`
5. `sz000660`
6. `sh600460`
7. `sh512760`
8. `sh601162`

## 数据与查询

- 使用固定长度为 8 的股票代码和行情数组，避免动态内存增长。
- 腾讯请求格式为 `http://qt.gtimg.cn/q=<code1>,<code2>,...<code8>`。
- 解析响应中的八条 `v_<code>="..."` 记录，按请求顺序写入行情数组。
- 每条行情只保留代码、价格和涨跌幅，不再解析昨收和成交量。
- 单条记录解析失败时保留该位置上次成功的数据；整个 HTTP 请求失败时保留全部旧数据。

## Nextion HMI 映射

每只股票占三个连续文本控件：

- 第 1 只：`t0` 代码、`t1` 价格、`t2` 涨跌幅
- 第 2 只：`t3` 代码、`t4` 价格、`t5` 涨跌幅
- 第 3 只：`t6` 代码、`t7` 价格、`t8` 涨跌幅
- 第 4 只：`t9` 代码、`t10` 价格、`t11` 涨跌幅
- 第 5 只：`t12` 代码、`t13` 价格、`t14` 涨跌幅
- 第 6 只：`t15` 代码、`t16` 价格、`t17` 涨跌幅
- 第 7 只：`t18` 代码、`t19` 价格、`t20` 涨跌幅
- 第 8 只：`t21` 代码、`t22` 价格、`t23` 涨跌幅

代码显示时去除 `sh`/`sz` 前缀。涨跌幅追加 `%`，负值显示绿色，零和正值显示红色，沿用当前 A 股配色。

## Web 配置与持久化

- 配置页显示八个独立输入框，字段名为 `code0` 至 `code7`。
- 输入必须是 `sh` 或 `sz` 加六位数字；保存前统一转为小写。
- 八个字段全部验证通过后才整体写入 NVS，避免部分更新。
- NVS 键使用 `code0` 至 `code7`；旧版单股票键 `code` 不再作为运行配置。
- 保存成功后清零股票刷新计时，使股票显示时段内下一轮循环立即批量刷新。

## 时段行为

- 工作日 09:30–11:30、13:00–15:00：每 5 秒批量查询八只股票。
- 工作日 11:30–13:00：每 10 分钟批量查询八只股票。
- 盘前、收盘后及周末：不查询股票，显示时间和天气。

## 验证

- 检查批量 URL、八条响应解析和全部 HMI 控件映射。
- 检查 Web 的有效输入、无效输入及重启后 NVS 恢复。
- 检查交易、午休、收盘和周末时段的刷新周期与界面切换。
- 使用可用的 Arduino 编译环境编译；若本机缺少工具链，则执行静态检查并明确说明。
