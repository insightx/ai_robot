# SSD1306 OLED (U8g2) on XIAO RP2040 Blink

Date: 2026-07-17

## Goal

Add a fixed-text SSD1306 128×64 OLED display to the existing NeoPixel blink sketch, using U8g2 over I2C.

## Hardware

| OLED | XIAO RP2040 |
|------|-------------|
| VCC  | 3V3         |
| GND  | GND         |
| SDA  | D4 (GPIO6)  |
| SCL  | D5 (GPIO7)  |

## Software

- Libraries: `U8g2lib`, `Wire`
- Constructor: `U8G2_SSD1306_128X64_NONAME_F_HW_I2C` (no reset pin)
- Display content (drawn once in `setup`): `XIAO RP2040`, `Hello`
- NeoPixel color cycle in `loop` unchanged
- Board package: Seeed XIAO RP2040 ≥ 2.7.2 recommended for Wire on D4/D5

## Out of scope

- Color/status sync on OLED
- Soft-I2C fallback unless HW I2C fails on device
